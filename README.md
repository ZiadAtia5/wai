# منصة وَعي

واجهة React مبنية باستخدام Vite وTypeScript وTailwind CSS. المشروع يعمل داخل Figma Make، وخادم التطوير مهيأ للعمل من خلال بيئة المشروع.

## تشغيل المشروع

```bash
npm install
npm run dev
```

أوامر التحقق والتنسيق:

```bash
npm run typecheck
npm run build
npm run format
npm run format:check
```

يحتاج الاتصال بالخادم إلى متغير البيئة `VITE_API_BASE_URL` في ملف `.env`.

## خريطة الملفات

```text
src/
├── api/                    # عميل HTTP ونقاط الاتصال وتجهيز بيانات الصفحات العامة
├── components/             # مكونات مشتركة بين الصفحات
│   ├── dashboard/          # نماذج وأدوات محتوى لوحة التحكم
│   └── layout/             # أغلفة الصفحات وشريط التنقل
├── hooks/                  # Hooks مشتركة، مثل تحميل بيانات API
├── pages/                  # صفحات التطبيق
├── utils/                  # وظائف مساعدة مثل رسائل التنبيه
├── App.tsx                 # التنقل بين الشاشات وتحميل الصفحات عند الحاجة
├── index.css               # الخطوط والألوان والأنماط العامة
├── main.tsx                # نقطة تشغيل React
└── types.ts                # الأنواع المشتركة
```

## إضافة ميزة جديدة

1. أضف نوع البيانات المشترك في `src/types.ts` أو بجوار الوحدة التي تستخدمه فقط.
2. أضف طلب الخادم في الملف المناسب داخل `src/api/`، واستخدم `apiRequest` بدل استدعاء `fetch` من مكونات الواجهة.
3. أنشئ الصفحة داخل `src/pages/`، وضع المكونات القابلة لإعادة الاستخدام في `src/components/`.
4. أضف وجهة الصفحة إلى نوع `View` في `src/types.ts`، ثم اربطها في `src/App.tsx` وأضف وسيلة التنقل المناسبة.
5. ضع التنسيقات الخاصة بالميزة في Tailwind داخل JSX، واستخدم `src/index.css` للألوان والخطوط والأنماط العامة فقط.

## قواعد تنظيم سريعة

- الصفحة مسؤولة عن تركيب مكوناتها وربطها بالبيانات؛ المكونات المشتركة تبقى مستقلة داخل `components/`.
- طلبات الشبكة وتعاملها مع الأخطاء تبقى في `api/`، ولا تُكرر إعدادات الاتصال داخل الصفحات.
- الأنواع الخاصة بميزة واحدة تبقى قريبة من تلك الميزة، والأنواع المستخدمة في أكثر من مكان توضع في `src/types.ts`.
- بعد تعديل الكود شغّل `npm run typecheck` و`npm run build` و`npm run format:check`.

### تجربة طلبات الالتحاق ببيانات تجريبية

من بيئة التطوير، افتح لوحة المعلم مع `?teacherEnrollmentMock=1` في عنوان الصفحة. ستظهر عينة طلبات محلية، ولن تُرسل الموافقة أو الرفض إلى الخادم. بيانات العينة موجودة في `src/mocks/teacherEnrollmentRequests.ts`.
